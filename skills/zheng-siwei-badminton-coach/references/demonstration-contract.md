# Teaching Demonstration Contract

Use this mode to explain and show a coach-side mixed-doubles route without learner video.

1. Require an action or rally module and desired phase; use level, training goal, or framework id only to narrow the teaching route.
2. Select an action-compatible framework before selecting media.
3. Prefer source ids declared by the selected framework, then require the reference action and phase to match.
4. Return the original source id, title, timestamp, jump link, visible facts, limitations, and frame or clip availability.
5. State whether the timepoint is `agent_reviewed`, `model_candidate`, or `timestamp_only`. Describe it as a public coach-video demonstration reference, not official certification or independent proof of role intent or tactical causality.
6. Use a still for posture or spacing navigation and a clip for process context. Never infer exact contact, racket-face angle, force, fixed gender roles, opponent intent, or calibrated 3D motion.
7. Return `no_reliable_same_phase_demonstration_frame` when the indexed evidence is insufficient. Never substitute another rally phase.
